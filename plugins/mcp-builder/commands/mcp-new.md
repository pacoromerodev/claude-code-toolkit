Create an MCP server using the `mcp-server-scaffold` skill.

$ARGUMENTS

Decide the primitives before writing any code — which capabilities are tools,
which are resources, which are prompts — and say why for each. Then write the
descriptions with the boundary against neighbouring tools in them, choose the
transport with `choose-transport`, and finish by running the audit script and
telling me what it says.
