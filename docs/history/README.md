# How this repository got here

The audits and plans behind the plugins, in the order they were written. They
are the record of what was found, what was decided and why; none of it is
needed to install or use a plugin.

| Document | What it is |
|---|---|
| [ROADMAP.md](ROADMAP.md) | The first plan: seven plugins, the course material each draws on, and the checklist for going public |
| [AUDIT.md](AUDIT.md) | The second audit: the safety defects, broken evals and content errors the first iteration left behind |
| [ROADMAP-v2.md](ROADMAP-v2.md) | The plan that fixed them, phase by phase, with every eval measurement and the plugins it retired |
| [AUDIT-v3.md](AUDIT-v3.md) | The third audit, against the English lessons, and the plan to make the repository public |

Course material is cited as `<course>.md:<line>`, paths in the private
academy notes repository; the text itself is not reproduced here.
